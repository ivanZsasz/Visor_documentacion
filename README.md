# Visor de Documentación — File Viewer & Sharing Platform

> Aplicación web para la gestión, visualización e interpretación multiformato de archivos (PDF, Markdown, JSON, código fuente y texto plano) con capacidades colaborativas de compartición de carpetas entre usuarios registrados.

---

## 🛠️ Características Principales

*   **Visualización Multiformato:** Interpretación y renderizado directo de archivos PDF, documentos Markdown (`.md`), estructurados (`.json`), código fuente (`.java`, `.html`) y texto plano (`.txt`).
*   **Gestión de Documentos:** Carga y organización centralizada de archivos en el sistema.
*   **Compartición Colaborativa:** Gestión de permisos para compartir carpetas completas con otros usuarios registrados mediante su dirección de correo electrónico.
*   **Autenticación de Usuarios:** Control de acceso seguro para garantizar la privacidad de las carpetas y documentos subidos.

---

## 🚀 Tecnologías Utilizadas

| Categoría | Tecnología / Herramienta |
| :--- | :--- |
| **Frontend** | HTML5, CSS3, JavaScript |
| **Renderizado** | Parsers de código/Markdown y visores integrados de PDF |
| **Persistencia y Control** | Sistema de almacenamiento de datos y gestión de permisos por correo |

## ⚙️ Requisitos e Instalación

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/ivanZsasz/Proyecto-Cortexdocs.git](https://github.com/ivanZsasz/Proyecto-Cortexdocs.git)
    ```
    *(Asegúrate de ajustar la URL si renombras el repositorio).*

2.  **Ejecutar la aplicación:**
    Abrir el archivo `index.html` en un navegador web o ejecutar mediante un servidor local como *Live Server* en VS Code.
